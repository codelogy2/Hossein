سایت مسیریابی مراسم عروسی

فایل‌ها:
- index.html : ساختار صفحه
- style.css  : ظاهر و طراحی واکنش‌گرا
- script.js  : اطلاعات مراسم و لینک اپلیکیشن‌ها

روش ویرایش:
فایل script.js را باز کن و فقط مقادیر داخل WEDDING_CONFIG را تغییر بده:
venueName = نام تالار یا باغ
address = آدرس کامل
latitude = عرض جغرافیایی
longitude = طول جغرافیایی
eventDate = تاریخ مراسم
eventTime = ساعت شروع

نکته مهم:
لینک Google Maps و Waze بر اساس قالب‌های رسمی لینک‌دهی آن‌ها ساخته شده‌اند.
قالب لینک نشان از ساختار نقشه وب نشان استفاده می‌کند.
لینک بلد در این نسخه یک قالب اولیه است و باید روی گوشی واقعی آزمایش شود؛ اگر بلد لینک اشتراک‌گذاری اختصاصی مکان را ارائه کند، بهتر است همان لینک را جایگزین baladUrl در script.js کنی.

برای اجرا، هر سه فایل را در یک پوشه نگه دار و index.html را باز کن.
برای انتشار، همین سه فایل را روی هاست استاتیک یا فضای میزبانی وب آپلود کن.
